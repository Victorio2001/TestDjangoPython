## Init Projet Victorio

### Création env 
```bash
python3 -m venv .venv    
```

### Start Env
```bash
.\.venv\Scripts\activate   
```

### Installation dépendances
```bash
pip install .
```

### Exécuter l'Application
```bash
python3 manage.py runserver
```

### Url
```bash
http://127.0.0.1:8000/admin/
```
